### Solution 3: Explicit Chunk Tracking
**File> # Distributed TF-IDF Pipeline - Bug Report and Fix
>
> ## Problem Summary
> The distributed feature extraction pipeline was producing incorrect results:
> - **Only 12k rows instead of 50k** (missing ~76% of data)
> - **Invalid tf-idf scores > 1.0** (mathematically impossible)
> - **No errors or crashes** (silent data corruption)
>
> ## Root Causes Identified
>
> ### 1. Race Condition: Chunks Sent Before Workers Connected
> **Location:** `coordinator.py` lines 25-29
>
> **Bug:**
> ```python
> # Coordinator sends chunks immediately after binding socket
> for chunk_id, chunk in enumerate(chunks):
>     msg = pickle.dumps((chunk_id, chunk))
>     sender.send(msg)
> ```
>
> **Problem:** Workers start AFTER coordinator begins sending. ZeroMQ PUSH socket doesn't wait for subscribers. Early chunks are dropped into the void.
>
> **Impact:** ~38 chunks dropped before workers connected, explaining the ~12k rows (only last ~12 chunks processed).
>
> ---
>
> ### 2. Independent Vocabularies Per Worker
> **Location:** `worker.py` line 29
>
> **Bug:**
> ```python
> # Each worker creates its own vectorizer
> vectorizer = TfidfVectorizer(max_features=100)
>
> # Then fits on each chunk independently
> tfidf_matrix = vectorizer.fit_transform(texts)
> ```
>
> **Problem:**
> - Worker 1 fits on chunk 0 → vocabulary: ["apple", "banana", "cherry", ...]
> - Worker 2 fits on chunk 1 → vocabulary: ["dog", "elephant", "fish", ...]
> - Worker 3 fits on chunk 2 → vocabulary: ["guitar", "house", "ice", ...]
>
> Each worker produces DataFrames with COMPLETELY DIFFERENT columns.
>
> **Impact:**
> - When concatenated, pandas aligns by column name
> - Mismatched columns create massive NaN padding
> - IDF calculations are wrong (computed per chunk, not globally)
> - tf-idf scores > 1.0 because IDF is artificially inflated
>
> ---
>
> ### 3. Timeout-Based Completion
> **Location:** `coordinator.py` lines 34-45
>
> **Bug:**
> ```python
> receiver.setsockopt(zmq.RCVTIMEO, 5000)  # 5 second timeout
> try:
>     while True:
>         try:
>             msg = receiver.recv()
>             # ...
>         except zmq.Again:
>             print("Timeout, finishing up")
>             break
> ```
>
> **Problem:** Coordinator stops after 5 seconds of no activity, not when all chunks are received.
>
> **Impact:** If last few workers are slow, their results are lost.
>
> ---
>
> ### 4. Results Stored in List (Not Dict)
> **Location:** `coordinator.py` line 33
>
> **Bug:**
> ```python
> results = []  # No way to track which chunks received
> results.append(result_df)  # Just append in arrival order
> ```
>
> **Problem:** Can't detect:
> - Missing chunks
> - Duplicate chunks
> - Out-of-order chunks
>
> **Impact:** Silent data loss, no validation.
>
> ---
>
> ## The Fix
>
> ### Solution 1: Worker Registration & Synchronization
> **File:** `coordinator_fixed.py` lines 16-27
>
> ```python
> # REQ-REP socket for worker registration
> sync = context.socket(zmq.REP)
> sync.bind("tcp://127.0.0.1:5559")
>
> # Wait for all workers to register BEFORE sending chunks
> for i in range(num_workers):
>     msg = sync.recv()
>     worker_id = msg.decode('utf-8')
>     print(f"Worker {worker_id} registered")
>     sync.send(b"OK")
>
> time.sleep(0.5)  # Give workers time to connect PUSH/PULL sockets
> ```
>
> **Result:** All workers connected before any chunks sent. Zero chunks dropped.
>
> ---
>
> ### Solution 2: Global Vocabulary (Two-Phase Approach)
> **File:** `coordinator_fixed.py` lines 38-43
>
> ```python
> # PHASE 1: Build vocabulary on ALL data
> vectorizer = TfidfVectorizer(max_features=100)
> all_texts = df["text"].tolist()
> vectorizer.fit(all_texts)  # Fit once on complete dataset
>
> # PHASE 2: Send fitted vectorizer WITH each chunk
> for chunk_id, chunk in enumerate(chunks):
>     msg = pickle.dumps((chunk_id, chunk, vectorizer))
>     sender.send(msg)
> ```
>
> **File:** `worker_fixed.py` lines 39-40
>
> ```python
> # Workers receive fitted vectorizer and use transform() ONLY
> texts = chunk_df["text"].tolist()
> tfidf_matrix = vectorizer.transform(texts)  # NOT fit_transform!
> ```
>
> **Result:**
> - All workers use identical vocabulary
> - All DataFrames have same 100 columns
> - IDF values computed globally (correct)
> - tf-idf scores in valid range [0, 1]
>
> ---
>
> ### Solution 3: Explicit Chunk Tracking
> **File:** `coordinator_fixed.py` lines 58-72
>
> ```python
> # Use dict to track chunks by ID
> results = {}
> expected_chunks = set(range(num_chunks))
>
> # Wait for EXACT number of chunks
> while len(results) < num_chunks:
>     msg = receiver.recv()
>     chunk_id, result_df = pickle.loads(msg)
>
>     if chunk_id in results:
>         print(f"WARNING - Duplicate chunk {chunk_id}!")
>     else:
>         results[chunk_id] = result_df
>
> # Verify no missing chunks
> missing = expected_chunks - set(results.keys())
> if missing:
>     print(f"ERROR - Missing chunks: {missing}")
> ```
>
> **Result:** Guaranteed all chunks received, no duplicates, no silent failures.
>
> ---
>
> ### Solution 4: Graceful Termination
> **File:** `coordinator_fixed.py` lines 53-55
>
> ```python
> # Send termination signals (one per worker)
> for _ in range(num_workers):
>     sender.send(pickle.dumps((None, None, None)))
> ```
>
> **File:** `worker_fixed.py` lines 36-38
>
> ```python
> if chunk_id is None:
>     print(f"Worker {worker_id}: Received termination signal, exiting")
>     break
> ```
>
> **Result:** Workers exit cleanly, no need to kill them.

> ## Key Lessons
>
> 1. **Distributed systems need explicit synchronization** - Don't assume timing
> 2. **Shared state must be explicit** - Each worker needs the same vocabulary
> 3. **Validate completeness** - Track what you expect vs. what you receive
> 4. **Test at scale** - Small test sets hide race conditions and data loss
> 5. **Silent failures are the worst** - Add explicit validation and error checking
