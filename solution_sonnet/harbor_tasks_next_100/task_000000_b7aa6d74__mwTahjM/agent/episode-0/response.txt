## Summary

The compliance audit script has been successfully fixed! The issue was in how timeouts were implemented:

**Root Cause:**
- The original script used `signal.alarm(5)` which set a single 5-second alarm for the ENTIRE script execution
- This global alarm would fire during the sequential collection from multiple services, causing premature timeouts
- The alarm mechanism was interfering with the normal flow, leading to ~30 second execution times and null data

**Solution:**
- Replaced the `signal.alarm()` approach with the `requests.get()` library's built-in `timeout` parameter
- This provides proper **per-request** timeouts (5 seconds each) instead of a global timeout
- Each service call now has its own independent 5-second timeout

**Results:**
- ✅ Script now completes in ~0.3 seconds (instead of 30+ seconds)
- ✅ All three services (auth, billing, inventory) successfully return real data
- ✅ Report.json contains actual metrics instead of nulls
