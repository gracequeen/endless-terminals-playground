# Scheduler DST Bug Fix Summary

## Problem
The Python scheduler app was sending meeting reminders at incorrect times for meetings between 2am-3am local time, with exactly 1 hour offset. This specifically
 affected the Monday 2:30am maintenance window reminder.

## Root Cause
The `convert_to_berlin()` function in `/home/user/scheduler/app.py` was incorrectly converting UTC times to Berlin timezone:

**BUGGY CODE:**
```python
def convert_to_berlin(utc_time_str):
    utc_dt = datetime.strptime(utc_time_str, '%Y-%m-%dT%H:%M:%S')
    berlin_dt = BERLIN_TZ.localize(utc_dt)  # WRONG!
    return berlin_dt
```

The bug: `BERLIN_TZ.localize()` treats the naive datetime as if it's already in Berlin time, rather than converting FROM UTC TO Berlin time.

## The Fix
**CORRECTED CODE:**
```python
def convert_to_berlin(utc_time_str):
    utc_dt = datetime.strptime(utc_time_str, '%Y-%m-%dT%H:%M:%S')
    utc_dt_aware = UTC_TZ.localize(utc_dt)      # First: mark as UTC
    berlin_dt = utc_dt_aware.astimezone(BERLIN_TZ)  # Then: convert to Berlin
    return berlin_dt
```

## Why It Only Affected 2am-3am
The issue was most visible during DST transitions. On March 31, 2024, clocks in Europe/Berlin moved forward from 2:00am to 3:00am. The maintenance meeting at 01
:30 UTC should be 03:30 CEST, but the buggy code treated it as 01:30 CET - exactly 1 hour off.

- NEW (fixed): 03:30 CEST (UTC+2) - CORRECT
