=== INCREMENTAL BACKUP CORRUPTION - ROOT CAUSE AND FIX ===

PROBLEM:
Incremental backups were creating corrupt archives that failed during extraction
with "unexpected EOF" errors or truncated files.

ROOT CAUSE:
In incremental.sh, the tar process was backgrounded (&) and the timestamp file
was updated IMMEDIATELY after, before waiting for tar to complete:

  tar --null -T - -czf "$ARCHIVE_DIR/$ARCHIVE_NAME" &
  TAR_PID=$!
  date +%s > "$TIMESTAMP_FILE"  # <-- UPDATED TOO EARLY!
  wait $TAR_PID

This created a race condition where:
1. The reference timestamp was updated before the archive finished writing
2. If tar was still running, the archive could be incomplete
3. The next incremental would use the wrong timestamp, missing files
4. Archives appeared to create successfully but were corrupt/incomplete

THE FIX:
Swapped lines 15-16 to update the timestamp AFTER tar completes:

  tar --null -T - -czf "$ARCHIVE_DIR/$ARCHIVE_NAME" &
  TAR_PID=$!
  wait $TAR_PID                  # <-- WAIT FIRST
  date +%s > "$TIMESTAMP_FILE"  # <-- THEN UPDATE

VERIFICATION:
- Created 3 test incremental backups
- All extracted successfully without errors
- New files properly included in incrementals
- No corruption or unexpected EOF errors

STATUS: FIXED ✓
