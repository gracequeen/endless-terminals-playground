# Performance Fix Summary

## Problem
JSON validator was processing at ~40 docs/sec instead of the expected 400-500 docs/sec.

## Root Cause
The `validate_document()` function was calling `preprocess_schema()` and creating a new `Draft7Validator` for EVERY document validation. With 200 test documents
:
- 200 jq subprocess calls (expensive)
- 200 validator compilations (expensive)
- No reuse of preprocessed schemas or compiled validators

## Solution
Implemented validator caching via `get_validator()` function:
- Added `_validator_cache` dictionary to store compiled validators by schema path
- Each unique schema is now only preprocessed once via jq
- Each validator is only compiled once and reused for all documents using that schema
- With 50 schemas and 200 documents, this reduced operations from 200 to ~50

## Results
- Before: 40.2 docs/sec
- After: ~1420 docs/sec
- Improvement: 35x faster
- Target met: Yes (required 400+ docs/sec)

## Code Changes
1. Added `_validator_cache = {}` global cache
2. Created `get_validator(schema_path)` function to manage cached validators
3. Modified `validate_document()` to use `get_validator()` instead of calling `preprocess_schema()` directly
