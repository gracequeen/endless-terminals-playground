# Meeting Reminder Timezone Bug - Fix Summary

## Problem
The Python scheduling app at `/home/user/scheduler/app.py` was sending meeting reminders at incorrect times - off by exactly one hour for meetings between 2am-3
am local time (Europe/Berlin timezone). The issue occurred when run via cron but appeared to work during manual testing.

## Root Cause
The bug was in the `convert_to_berlin()` function in `app.py` (line 28 of the original code):

```python
# BUGGY CODE:
def convert_to_berlin(utc_time_str):
    utc_dt = datetime.strptime(utc_time_str, '%Y-%m-%dT%H:%M:%S')
    berlin_dt = BERLIN_TZ.localize(utc_dt)  # WRONG!
    return berlin_dt
```

The issue: `BERLIN_TZ.localize(utc_dt)` treats the naive datetime as if it's already in Berlin time, rather than converting FROM UTC TO Berlin. This causes inco
rrect timezone offset calculations, especially during DST transitions.

## Solution
Fixed the timezone conversion to properly convert from UTC to Berlin:

```python
# FIXED CODE:
def convert_to_berlin(utc_time_str):
    utc_dt = datetime.strptime(utc_time_str, '%Y-%m-%dT%H:%M:%S')
    utc_dt_aware = UTC_TZ.localize(utc_dt)      # Make UTC-aware
    berlin_dt = utc_dt_aware.astimezone(BERLIN_TZ)  # Convert to Berlin
    return berlin_dt
```
